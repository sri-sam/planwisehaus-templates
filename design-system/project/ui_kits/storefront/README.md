# Etsy Storefront UI Kit

Marketing-side recreation: how a PlanWiseHaus product listing presents to a shopper on Etsy. The visual vocabulary mirrors Etsy's product detail page (large image gallery → title + price → variations → description below the fold) while the brand chrome stays PlanWiseHaus: cream background, serif display headings, gold rules.

## Components

- `StorefrontFrame.jsx` — Etsy-shaped header + footer chrome
- `ProductGallery.jsx` — large hero image + 4 thumbnails
- `ProductInfo.jsx` — title, star rating, price, "Add to cart" panel
- `Highlights.jsx` — bullet list of template features
- `Reviews.jsx` — sample reviewer cards
- `RelatedProducts.jsx` — cross-sell grid of other templates

The page demonstrates Annual Budget Spreadsheet 2025 as the showcased product.
